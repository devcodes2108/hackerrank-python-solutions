# HackerRank Python Solutions

<img src="assets/quick-push-banner.svg" alt="Quick Push workflow illustration" width="100%" />

This repository is a growing collection of Python solutions for HackerRank challenges and programming exercises.

Solutions are submitted through QUICK PUSH, a VS Code extension developed by this repository's owner, devcodes2108. Instead of first adding a solution file to the repository manually, you paste your solution code into the extension. After you authorize your GitHub account and select a repository, QUICK PUSH creates the file there and commits and pushes the change.

You can find the QUICK PUSH extension here:
https://github.com/devcodes2108/quick-push

This repository keeps completed HackerRank solutions together so they are easy to review, reuse, and build upon. When a solution is sent to this repository through QUICK PUSH, the extension creates the file and publishes the committed change to GitHub.

The repository is intended as an organized reference for practice, revision, and learning from previously solved challenges.

## Workflow

1. Solve a HackerRank challenge in Python.
2. Paste the solution code into [QUICK PUSH](https://github.com/devcodes2108/quick-push).
3. Authorize your GitHub account if prompted, then select the repository where the solution should go.
4. QUICK PUSH creates the solution file in the selected repository, then commits and pushes it to GitHub.
5. Repeat to grow an organized collection of solutions that is easy to review and revisit.

QUICK PUSH is developed by devcodes2108, the owner of this repository. The animated illustration above highlights the extension's workflow.
